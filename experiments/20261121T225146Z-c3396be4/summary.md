# Протокол

Контроли — штатный BM25 с учётом статуса и архивный BM25 с бонусом близости. Общий eval, K=1/5/10/20/50/100. Выбор на разработческой части по nDCG@10, затем Recall@10, MRR@10 и задержке. Проверка один раз на отложенных ящиках и на публичных 99 запросах. Для независимой диагностики строим воспроизводимую слабую разметку по явно запрошенной фразе и периоду, включая контрольные запросы без периода. Не используем эталонные границы при поиске.

После разработческой части (190 запросов, по трём вариантам nDCG@10 = 0,6126) проверяем обратный порядок дат и глагола получения и нечёткое ранжирование по дням для интервалов до восьми дней. Независимый диагностический срез из 67 пересекающихся интервалов строится только из полностью покрытых исходными оценками организаторов дней. Финальный выбор по nDCG@10 на разработческой части, контрольные пять ящиков до выбора не открываем.
