# Поиск по периоду на 60 контрольных запросах

Оба варианта из `12ebbd0` проверены на замороженном наборе из 60 запросов к пяти ящикам и на публичных 99. Использован общий CLI eval. K = 1, 5, 10, 20, 50, 100. Ошибок в четырёх прогонах нет. Эталонные границы использовались только для сверки распознавания и подсчёта выданных документов в периоде.

| Набор | BM25 со статусом | BM25 внутри периода | Нечёткий BM25 по дням |
| --- | ---: | ---: | ---: |
| Все 60, nDCG@10 | 0,8344 | 0,8572 | 0,8572 |
| 17 запросов с диапазоном, nDCG@10 | 0,5889 | 0,6693 | 0,6693 |
| Публичные 99, nDCG@10 | 0,9976 | 0,9976 | 0,9976 |

На локальном наборе парсер правильно распознал границы у пяти из 17 запросов с диапазоном. Для 12 формулировок период не распознан. Писем вне заданного периода в первой десятке стало 53 из 170 против 77 из 170. Относительно основного BM25 у каждого варианта четыре улучшения по nDCG@10 и ноль ухудшений. Варианты меняют порядок первой десятки в пяти запросах относительно друг друга, а агрегированные метрики совпадают. На публичных 99 порядок результатов у обоих совпадает с прежним BM25 со статусом. Состав скрытого набора организаторов неизвестен. [Агрегаты](comparison.json)

## Воспроизведение

Источник реализации — [коммит исследования](https://github.com/GalimovKI/pentada-astr/commit/12ebbd0090c7a02ed120ea58f436e51a407ad18a). CLI и остальные файлы backend взяты из `dev` на `fb964f0`, который был влит в локальную ветку на `379e4ec`. Код backend в этой ревизии и в исследовательской ветке различается только наличием модуля `receipt_period.py`.

Положите [обёртку](run.py) и конфигурации в один временный каталог. Из корня checkout скопируйте в него точный модуль из коммита исследования. В `data_dir` укажите замороженный контрольный набор. Для публичного сравнения подставьте архив организаторов. Вывод сохраняется в новый каталог для каждого прогона.

```sh
git show 12ebbd0:backend/src/mail_search/search/receipt_period.py > "$tmp_dir/receipt_period.py"
for mode in early-v2 daily; do
  uv run --project backend --locked --extra minilm python "$tmp_dir/run.py" run \
    --dataset "$data_dir" --engine mail_search.search.receipt_period:create_engine \
    --config "$tmp_dir/$mode.json" --output "$out_dir/$mode"
done
```
