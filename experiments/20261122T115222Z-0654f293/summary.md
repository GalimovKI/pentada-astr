# Опечатки и родственные слова при отправке запроса

Запросы «штрфа», «штрафик» и «оштрафовали» нашли те же 662 письма, которые находил запрос «штраф», в том же порядке. При выключенной коррекции каждый из трёх вариантов давал ноль результатов. Все 662 документа содержат последовательность букв «штраф». Проверка проводилась в ящике `box-12259a301ee2` на 2030-01-01 с порогом 0,84. Измерение характеризует покрытие лексического варианта. Для этих диагностических запросов нет разметки релевантности.

На 99 исходных размеченных Mail Public запросах оба режима дали одинаковые списки писем вплоть до сотой позиции. Ошибок 0. Macro Recall@10 0,937564, nDCG@10 0,997610, MRR@10 1,000000. Все значения и число проверенных запросов по каждому K приведены в `baseline/metrics.json` и `combined/metrics.json`. Этот набор не показывает прироста качества и не измеряет качество автодополнения при наборе.

В обоих запусках использован event-aware BM25, один и тот же датасет и неизменённый общий eval для K 1, 5, 10, 20, 50 и 100. Флаги нового запроса — `correct_typos=true`, `expand_word_forms=true`. При измерении ранжирования порог не применялся. Скрипт отправляет HTTP-запросы локальному FastAPI TestClient. Почтовый сервис ищет штатным движком. Только чтение превью после ранжирования обращается к локальным данным в памяти через эквивалентную проверку ящика и даты. Скорость не измерялась.

## Воспроизведение

Примените `check.py` из этой записи к чистым checkout ревизий `1b739cdef92df31ae025ec88628768502cf7340c` и `5ffd93c2edec1680da7f64e0042b7c97b7d7726d` в таком порядке, сохраняя обе папки в одном выходном каталоге. Установите зависимости backend по lock-файлу. Для каждого checkout из корня выполните следующие команды, подставляя `baseline` для исходной ревизии и `combined` для новой.

```sh
PYTHONPATH=backend/src backend/.venv/bin/python "$CHECK_SCRIPT" "$MAIL_PUBLIC_ARCHIVE" "$OUTPUT" "$MODE"
```

Скрипт сохраняет полную выдачу, строки per-query и диагностику в выходной каталог. SHA256 manifests, кода eval и зафиксированные идентификаторы кода лежат в `run.json` каждого запуска. Исследование использовало CPU и один последовательный клиент.
