# Сравнение E5 и BM25

По каждому запросу движки получали только текст, ящик и дату. Общий eval сравнивал выдачу до 100 документов с разметкой при K = 1, 5, 10, 20, 50 и 100. В SmartMail 99 запросов. В каждой языковой версии EnronQA 2 432 запроса, русская версия переводит английскую. Все прогоны завершились без ошибок. Значения ниже получены на CPU Apple M1 Pro с INT8 ONNX multilingual-e5-small. Для локальных вычислений использовались заранее подготовленные векторы писем.

| Корпус | Метод | Recall@10 | nDCG@10 | MRR@10 |
|---|---|---:|---:|---:|
| SmartMail | BM25 с учётом событий | 0.9376 | 0.9976 | 1.0000 |
| SmartMail | E5 cosine | 0.2961 | 0.2004 | 0.2245 |
| SmartMail | BM25 + E5 (RRF) | 0.9366 | 0.9949 | 1.0000 |
| SmartMail | E5 → BM25 | 0.9342 | 0.9935 | 0.9949 |
| SmartMail | BM25 → E5 | 0.8547 | 0.8895 | 0.9163 |
| SmartMail | E5 с днём получения | 0.8507 | 0.8834 | 0.9112 |
| EnronQA EN | BM25 с учётом событий | 0.9893 | 0.9483 | 0.9349 |
| EnronQA EN | E5 cosine | 0.9457 | 0.8534 | 0.8237 |
| EnronQA EN | BM25 + E5 (RRF) | 0.9905 | 0.9446 | 0.9296 |
| EnronQA EN | E5 → BM25 | 0.9856 | 0.9455 | 0.9323 |
| EnronQA EN | BM25 → E5 | 0.9544 | 0.8596 | 0.8291 |
| EnronQA RU | BM25 с учётом событий | 0.9564 | 0.8834 | 0.8594 |
| EnronQA RU | E5 cosine | 0.9087 | 0.7886 | 0.7500 |
| EnronQA RU | BM25 + E5 (RRF) | 0.9609 | 0.8831 | 0.8573 |
| EnronQA RU | E5 → BM25 | 0.9523 | 0.8815 | 0.8582 |
| EnronQA RU | BM25 → E5 | 0.9141 | 0.7931 | 0.7543 |

Во всех гибридах BM25 учитывает события, а E5 учитывает явно запрошенный день получения. Отдельный контроль E5 с тем же фильтром дня добавлен после регистрации трёх стратегий для оценки вклада даты. Два каскада используют до 50 кандидатов. Слияние RRF объединяет два списка по 50 с весами 0,75 для BM25 и 0,25 для E5 при константе 10. В каскаде E5 → BM25 вклад BM25 в конечную оценку равен 0,75, вклад косинусной близости — 0,25.

На SmartMail фильтр дня получения сам по себе поднимает nDCG@10 чистого E5 с 0,2004 до 0,8834. Добавление лексических признаков дальше улучшает порядок выдачи. Из гибридов ближе всего к BM25 по nDCG@10 здесь RRF. На обеих версиях EnronQA RRF дал наибольший Recall@10. По nDCG@10 лидировал исходный событийный BM25 на всех трёх наборах. Эти наблюдения относятся к фиксированным публичным запросам.

## Порог в почте

Порог интерфейса подбирался отдельно от сравнения при фиксированном K. Существующий скрипт `scripts/calibrate_mail_thresholds.py` максимизирует среднее по двум корпусам значение macro-F1 на выбранных для настройки ящиках. Для настройки использованы 58 запросов SmartMail и 60 EnronQA EN, для проверки на других ящиках — 41 и 40 соответственно. Пользователь может изменить порог каждой модели в почте.

| Пресет | Порог | F1, SmartMail | F1, EnronQA EN |
|---|---:|---:|---:|
| `e5-bm25-rrf` | 0.80 | 0.755 | 0.631 |
| `e5-then-bm25` | 0.84 | 0.735 | 0.883 |
| `bm25-then-e5` | 0.84 | 0.613 | 0.573 |

## Воспроизведение

Для локальной проверки выберите архив SmartMail или один из двух архивов в `data/benchmarks/enronqa-ru/`. Установите зависимости проекта для локального инференса, скачайте закреплённый ONNX-граф и выполните в новом каталоге результатов:

```sh
uv sync --project backend --locked --extra minilm
python3 infra/docker/fetch_e5.py --device cpu --output artifacts/models/e5
backend/.venv/bin/python experiments/e5-hybrids/benchmark.py \
  --dataset data/raw/mipt_mail_search_participants.zip \
  --model-dir artifacts/models/e5 --index-dir artifacts/e5-indexes \
  --output reports/quality/runs/e5-hybrids-mail \
  bm25-event-aware e5-cosine e5-bm25-rrf e5-then-bm25 bm25-then-e5 e5-receipt-day-control
```

Каждый пресет записывает полную выдачу, показатели отдельно по каждому запросу, сводные метрики и конфигурацию. Время локального вызова лежит в `per_query.jsonl`. Колонки задержки на сайте заполняются при прогоне серверного eval. [Запись эксперимента](https://github.com/GalimovKI/pentada-astr/tree/team-memory/experiments/20261122T111606Z-497e2e58)
