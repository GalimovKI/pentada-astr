# Пороги выдачи в dev-почте

Цель — отбирать переменное количество писем по оценке соответствующего движка. Для каждого из шести движков выбирается собственный порог, максимизирующий среднее двух корпусных macro-F1 на обучающих ящиках. При равенстве выбирается более строгий порог. Стандартный ranking eval использует прежние K. Интерфейс передаёт relevance_threshold и получает все совпадения, включая равные порогу.

Основной набор — все 99 публичных запросов (58 для подбора, 41 для проверки). В EnronQA EN взяты до 10 запросов на каждый ящик в порядке SHA-256 идентификатора (60 для подбора, 40 для проверки). Для проверки берётся каждый третий ящик в порядке хеша идентификатора. Macro-F1 относится к множеству выданных идентификаторов и бинарным qrels. Для top-10 сохранён порядок исходной модели.

| Модель | Порог | F1 публичная почта | top-10 | F1 EnronQA EN | top-10 |
|---|---:|---:|---:|---:|---:|
| e5-cosine | 0.835 | 0.081 | 0.072 | 0.510 | 0.173 |
| bm25 | 0.76 | 0.094 | 0.086 | 0.864 | 0.177 |
| bm25-stemmed | 0.75 | 0.692 | 0.784 | 0.864 | 0.177 |
| bm25-improved | 0.84 | 0.731 | 0.784 | 0.885 | 0.177 |
| bm25-event-aware | 0.84 | 0.738 | 0.881 | 0.885 | 0.177 |
| bm25-minilm | 0.63 | 0.738 | 0.881 | 0.864 | 0.177 |

На EnronQA с преимущественно одиночными ответами порог часто улучшает F1. На публичной почте для ряда движков top-10 даёт более высокий F1. Порог не гарантирует качества для любого ящика.

Код выполнен локально из рабочего дерева во время разработки. Итоговый локальный коммит: e674bbfdb159e67031f59cb7a534ac479d540678. Исходная база d2ca7bd5b401f4ca6805f3f8e9772db0267a067f. Проверочный прогон выполнялся на CPU с закреплёнными ONNX-графами amd64 MiniLM и E5.

Команда из корня для каждого ID в таблице:

```bash
backend/.venv/bin/python scripts/calibrate_mail_thresholds.py --official data/raw/mipt_mail_search_participants.zip --enron data/benchmarks/enronqa-ru/enronqa-en-en.zip --e5-dir artifacts/models/e5 --minilm-dir artifacts/models/minilm --index-dir /tmp/e5-indexes --model bm25
```
