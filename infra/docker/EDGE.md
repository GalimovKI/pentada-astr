# Frontend на VPS, backend на учебном хосте

Полная пошаговая инструкция находится в [DEPLOYMENT.md](../../DEPLOYMENT.md).

В ней описаны передача одного коммита на оба сервера, подготовка rootless Docker,
корпуса и БД, ограниченный SSH-туннель, запуск Caddy, публичная проверка, HTTPS,
обновление и откат. Команды разделены по месту исполнения: ноутбук, VPS, учебный хост.
