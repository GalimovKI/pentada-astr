# Поддержка выделенной GPU для dev E5

На хосте Brain Lab драйвер 580.82.07 обнаруживает четыре A100 PCIe 80 ГБ. Команда `nvidia-ctk cdi list` показывает каждую карту по индексу и UUID. Все четыре на момент проверки выполняли работу. Для постоянного dev-инференса нужен согласованный номер или UUID.

В dev добавлен режим E5 CUDA с ONNX FP32 и отдельной матрицей корпуса по хешу весов. При создании сессии движок профилирует пробный запрос и проверяет размещение матричных операций на CUDA. Ко времени публикации проверены 73 теста backend с PostgreSQL, 9 тестов CI/CD, настройки GPU для обоих контейнеров в объединённом Compose. Проверка на действующей GPU ожидает выделения карты. Замеров производительности GPU пока нет. [Коммит](https://github.com/GalimovKI/pentada-astr/commit/1420b74c1590681dddb4a4005d2cd6aaf26d9698)
