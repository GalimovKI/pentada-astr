# Гибрид BM25 и MiniLM в каталоге dev

Добавлен выбор «BM25 по дате + MiniLM (75/25)» для поиска и оценки. BM25 даёт кандидатов, MiniLM меняет порядок первых 20 через RRF. Dev Compose включает зависимости ONNX и загружает закреплённые веса при сборке. Загрузка проверяет SHA-256 модели и токенизатора. [Коммит dev](https://github.com/GalimovKI/pentada-astr/commit/4f362ec2e5ebd818b9042ce5781abe624b299d20) · [Исходный прогон](https://github.com/GalimovKI/pentada-astr/tree/8710164/experiments/20261121T150307Z-e539c8bf)

На 99 публичных запросах ARM64-граф побайтно воспроизвёл исходные метрики и выдачу. Для графа amd64 с квантованием AVX2 на локальной ARM64-машине общий eval дал Recall@10 0,936646, nDCG@10 0,993044, MRR@10 0,994949. В полном прогоне через dev API на той же машине метрики совпали с offline eval, ошибок 0. Локальный серверный p99 225,747 мс относится к последовательному ASGI-прогону с K = 100 и без отдельного прогрева.

Локально подтверждены каталог, выбор поиска по модели и завершение dev eval, 71 тест backend с PostgreSQL и 9 тестов развёртывания. Проверена конфигурация Compose с dev overlay. Веса, корпус и списки документов остаются вне Git. Эксплуатационные настройки сервера и состояние CI проверяются отдельно от этих замеров.
