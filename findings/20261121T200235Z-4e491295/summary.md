## Vectrix ART-E

В англоязычном синтетическом корпусе 1 964 уникальных письма с датой отправки. В `tasks_eval.parquet` 184 запроса к 51 ящику. Из них 73 запроса к 34 ящикам помечены как поиск одного письма, но у одного из 73 два размеченных источника. Во всех 422 парах запрос–источник письмо существует и адрес ящика указан среди отправителя или получателей To/Cc/Bcc. Письма позже дня запроса среди источников отсутствуют. Четыре пары имеют ту же календарную дату, что и запрос. При строгом отсечении до начала дня такие пары пришлось бы исключить, а наш формат оценки на календарных датах допускает равенство. [Карточка закреплённой версии](https://huggingface.co/datasets/TonicAI/vectrix-art-e/blob/f64b40aa3be2771971274fe253ccb04522d53ac5/README.md).

У 64 из 73 запросов первого уровня все источники отправлены за день до даты запроса. У 61 из этих 64 простой шаблон не обнаружил выражений вроде yesterday, last week, дня недели или даты с названием месяца. Шаблон оценивает наличие отдельных календарных выражений и не размечает их смысл. Медиана числа кандидатов в ящике до начала дня запроса равна 96. За один предыдущий день медиана равна одному письму, максимум шести. Возврат всех писем за этот день даёт макро-Recall@10 **0,8767** для 73 запросов без использования текста. Это диагностический расчёт по таблицам, модель не запускалась. Поэтому сырая разметка Vectrix склонна поощрять приоритет свежих писем, как и публичный набор хакатона, хотя в нём привязка к дате выражена в самих запросах.

В `train` и `eval` пересекаются все 51 ящик из `eval`, 277 исходных писем и числовые идентификаторы всех 184 заданий `eval`. При адаптации нужно включить split в идентификатор запроса. Для независимой проверки после обучения нужно контролировать пересечения по исходным письмам и ящикам. Пилот подходит для отдельной проверки доступности письма в выбранном ящике и на дату сценария. Для проверки приоритета свежих писем нужен срез по возрасту эталона.

Для воспроизведения скачайте из указанной ревизии `emails.parquet`, `tasks_train.parquet` и `tasks_eval.parquet`. В каталоге с файлами выполните `uv run --no-project --python 3.12 --with pyarrow==26.0.1 python audit-vectrix.py`. Результат и SHA-256 входов сохранены в [vectrix-audit.json](vectrix-audit.json).

## PaperTrail-Bench

Локальная генерация из пресета `bench` с `seed=42` дала 15 515 писем в 3 882 цепочках, 8 104 документа и 326 запросов. Есть 55 заданий на поиск записи, 55 на версии заказа, 55 на условия, действовавшие на определённую дату, и 55 запросов без ответа. Для первых трёх групп у каждого запроса есть хотя бы один `message_id` в поле `evidence`. Все эти идентификаторы проверены по `ground_truth/messages.jsonl`. Генератор делает похожие версии счетов, исправления заказов и цитирование предыдущих писем. Запросы англоязычные и шаблонные, а часть требует вложений или нескольких писем. Поиск внутри конкретного личного ящика потребует отдельного определения доступности по заголовкам. Дату действия условий следует трактовать отдельно от даты доступности письма. [Исходники генератора](https://github.com/NienHQ/papertrail-bench/tree/37a9b8b335e78713bad43cdb2ff73c3d474f8fc5).

Для воспроизведения из корня указанного коммита выполните `PYTHONPATH=generator/src uv run --no-project --python 3.12 python -m papertrail generate --preset bench --seed 42 --out /path/to/empty-output`. Сведения о подсчёте и SHA-256 сохранены в [papertrail-audit.json](papertrail-audit.json). Для проверки связей сгруппируйте `questions.jsonl` по `category` и для каждого запроса соберите неповторяющиеся `evidence[].message_id`, затем сверьте с идентификаторами из `ground_truth/messages.jsonl`.

## Следствие для проекта

PaperTrail даёт отдельную проверку на похожих письмах с разным статусом и версиями. Для выбора модели под хакатон приоритетнее независимо сформулированные русские запросы к пяти ящикам, которых нет в публичной разметке. Полезные группы включают запросы без даты или с диапазоном, похожие письма с противоположным статусом и письма, отправленные задолго до запроса. Это даёт возможность сравнить BM25 с учётом статуса и BM25 с MiniLM без опоры на один вчерашний день. Метрики существующего движка на внешних корпусах пока не измерялись.
