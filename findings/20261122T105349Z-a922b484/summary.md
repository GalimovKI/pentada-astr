# Вход в SmartMail dev

Dev выдаёт HTML-форму и проверяет сеанс на сервере при открытии почты, API и ресурсов приложения. При выходе backend отзывает сессию, максимальный срок сессии — восемь часов. В этой конфигурации Uvicorn использует один процесс. Перезапуск backend завершает открытые сеансы.

При развёртывании файл проверки пароля должен существовать до проверки GPU. Docker Compose использует bind mount файла с `create_host_path: false`. Код проверки сеансов находится в `backend/src/mail_search/api/dev_login.py`, правила доступа — в `infra/docker/dev-access.caddy`.

На опубликованном сайте в Chromium проверены ошибка пароля, вход с существующей учётной записью, чтение письма, обновление страницы и выход. API возвращает 401 до входа и после выхода. На основной сайт можно зайти без входа. Автотесты сессии и регрессии отзыва находятся в `backend/tests/unit/test_dev_login.py`.
