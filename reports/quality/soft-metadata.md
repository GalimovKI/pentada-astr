# Мягкий учёт даты и участников переписки в E5

Эксперимент `20261121T120858Z-bb683077`, код `67ea14cd69ef68b8f3306ddeaf329fcc4142b8aa` в ветке `timofey-research`. Сравнение продолжает [эксперимент E5](https://github.com/GalimovKI/pentada-astr/blob/80dbbe3/reports/quality/e5-experiments.md). Гипотеза состояла в том, что выделение даты получения, отправителя и адресата позволяет поднять нужные письма без исключения писем с неполными заголовками.

## Устройство прогона

Во всех вариантах E5 ранжирует по косинусной близости после общей подготовки запроса парсером прототипа. Вариант «E5» отключает метаданные при ранжировании. Кандидаты принадлежат выбранному ящику и доступны на дату запроса. Неизвестная дата допускается. Контроль с жёстким днём оставляет только письма распознанного дня. Мягкий вариант сохраняет кандидатов и добавляет к близости бонус за дату получения, равный 0,16 × exp(−|расхождение в днях| / 1,5), и бонус 0,12 за совпадение человека в соответствующем заголовке. Эти параметры зафиксированы до первого измерения. Неподтверждённые поля баллов не дают.

Правила и Qwen получают одни и те же найденные в запросе фрагменты. Даты распознаются регулярными выражениями. Люди предлагаются по адресу email или имени из заголовков выбранного ящика с приближённым сопоставлением словоформ. Qwen2.5-0.5B-Instruct оценивает три варианта роли для каждого фрагмента и умножает бонус на вероятность выбранной роли среди трёх вариантов. Для события, простого упоминания и неопределённой роли бонус отсутствует. Параметры извлечения и подсказка опубликованы в [roles.py](../../experiments/soft-metadata/roles.py).

## Разметка и интерпретация

- Публичные 99 запросов не содержат явных требований к отправителю. Совпадение nDCG@10 с жёсткой датой отражает качество на этом наборе, списки результатов могут различаться.
- Для 76 запросов из тех же 99 в исходной разметке есть релевантное письмо с явным email отправителя. Для каждого добавили «от <адрес>», выбрав наиболее частый явный адрес среди релевантных писем. Релевантными оставили письма с этим адресом. Разметка автоматически построена по тому же извлекателю заголовков. Это проверка точных адресов на реальном корпусе, с зависимостью между построением разметки и алгоритмом. Прирост добавления участников к мягкой дате составил 0,03901 nDCG@10.
- 16 написанных для эксперимента запросов предъявлены к отдельному искусственному ящику из 72 писем. Различаются отправитель, получатель, упомянутый человек, дата получения, дата встречи и тема. Разметка строится по исходным полям генератора, независимо от парсера. Точные наборы фильтров правила извлекли для 15/16 запросов, Qwen для 3/16, во всех трёх ожидаемый набор был пуст. Из 21 требуемой привязки роли правила нашли 20, Qwen — 0. В правилах пропущен адресат в «Письма Борису о смете». Малый набор и шаблонные письма ограничивают перенос результата.
- На публичных запросах Qwen выбрала неопределённую роль для даты 99/99 раз. Для 76 явных адресов 6 классифицированы как отправитель, 11 как получатель, 59 как другое. Проверка относится к данной модели, промпту и способу классификации. Имя вне словаря, псевдонимы, несколько одноимённых участников и качество извлечения заголовков в живой почте требуют отдельной разметки.
- Результаты поддерживают использование мягких правил как исходного варианта. Для другого обученного экстрактора первую проверку стоит проводить на независимых пользовательских формулировках с разметкой ролей. Серверная задержка под нагрузкой в этом эксперименте не измерялась.

## Воспроизведение

Brain Lab, NVIDIA A100, Python 3.12, torch 2.13.0+cu130, transformers 5.14.1, numpy 1.26.4. Энкодер, токенизация до 512 токенов и средний пулинг взяты из экспериментальной ветки команды. E5 использует float32, Qwen — bfloat16. Установить зависимости backend и перечисленные ML-библиотеки в выбранное окружение. На checkout кода эксперимента из корня репозитория выполнить следующие команды. HF CLI используется для подготовки открытых весов, модель извлечения выбирается по локальному пути.

```sh
git worktree add --detach ../pentada-e5-reference 80dbbe396dc38ac92535dfe9b079787ccf944cb8
export PYTHONPATH="../pentada-e5-reference/experiments/mailsearch-e5:backend/src"
export OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 TOKENIZERS_PARALLELISM=false
hf download intfloat/multilingual-e5-small --revision 614241f622f53c4eeff9890bdc4f31cfecc418b3 --include '*.json' model.safetensors sentencepiece.bpe.model
hf download Qwen/Qwen2.5-0.5B-Instruct --revision 7ae557604adf67be50417f59c2c2f167def9a775 --local-dir artifacts/models/soft-qwen --include '*.json' '*.txt' model.safetensors
archive=data/raw/mipt_mail_search_participants.zip
python experiments/soft-metadata/encode.py "$archive" artifacts/indexes/soft-e5.npz
python experiments/soft-metadata/run.py "$archive" artifacts/indexes/soft-e5.npz artifacts/models/soft-qwen reports/quality/runs/soft-repro
uv run --project backend --locked mailsearch score --predictions reports/quality/runs/soft-repro/public/rule_soft/predictions.jsonl --output reports/quality/runs/soft-verified
```

В новом каталоге прогона сохраняются метрики, ранжированные списки, результаты по запросам и роли извлечённых фрагментов. Предсказания и материалы с содержимым запросов остаются локальными.
