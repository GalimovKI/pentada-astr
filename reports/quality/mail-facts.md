# Извлечение автора и дат из писем и поисковых запросов

Эксперимент `20261121T125502Z-8607991b`. Код итогового прогона — `b1e17effcfda7224981c4fff8dd359cd45764e2a`, ветка `timofey-research`. Локальная Qwen3-1.7B извлекает автора и выражения дат с ролями из исходного текста. Возвращается исходное написание, роль даты и символьные смещения первой дословной цитаты. Дата получения из метаданных передаётся отдельно. Относительный день получает календарное значение только при известной точке отсчёта. Для писем это дата получения, для запросов — дата запроса.

В письме явный внешний заголовок От/From имеет приоритет при формировании результата. При его отсутствии модель называет автора, а код ищет названное значение в подписи. В запросе модель извлекает искомого отправителя в исходном падеже. Выражение даты проверяется на присутствие календарного обозначения и приводится к ISO для поддерживаемых форматов. Роли — получение/отправка самого письма, событие, крайний срок и неизвестная роль. Если одна и та же формулировка встречается несколько раз, координаты указывают первое вхождение. Цитата подтверждает наличие текста, роль проверяется отдельно.

## Точность

Каждая ячейка показывает число полностью верных ответов для поля. Автор совпадает с эталонной цитатой или правильно оставлен пустым. Даты оцениваются по точному совпадению всего набора пар «роль и календарный день», включая отсутствие лишних фактов. В 134 оценённых примерах итоговой версии все ответы удалось разобрать.

| Набор | Число | Автор | Все даты с ролями | Оба поля |
| --- | ---: | ---: | ---: | ---: |
| Выбранные письма корпуса, использованные при доработке | 8 | 8 | 7 | 7 |
| Первые примеры, письма / запросы | 5 / 6 | 5 / 6 | 4 / 4 | 4 / 4 |
| Дополнительные примеры второго прогона, письма / запросы | 4 / 4 | 4 / 2 | 2 / 3 | 2 / 2 |
| Новые после фиксации подхода, письма / запросы | 4 / 4 | 4 / 2 | 3 / 4 | 3 / 2 |
| Публичные шаблонные запросы без отправителя | 99 | 99 | 99 | 99 |

В восьми выбранных письмах четыре правильных пустых автора, два значения из явных заголовков и две подписи. Эта выборка входила в отладку. На восьми последних примерах оба поля верны в 5/8. Например, «до 2028-09-26» при просьбе закончить проверку модель назвала датой события, а в запросе «Что Артём прислал вчера?» пропустила отправителя. В одном письме корпуса правильному сроку отгрузки дополнительно приписана роль события.

Исходная версия `6cd634b` дала оба поля верно в 0/8 писем корпуса и 99/99 публичных запросов. В версии `acc499f` переход на отдельные списки ролей улучшил извлечение в примере с подписью, но ухудшил результат на публичных запросах до 0/99. В финальной версии разделены промпты для писем и запросов, добавлены проверки подписи и календарной цитаты. Все три прогона использовали один локальный чекпойнт, детерминированную генерацию и один A100 Brain Lab. Серверное время ответа и качество ранжирования не измерялись. Экстрактор доступен как отдельная JSONL-команда; основной поисковый движок использует прежнюю конфигурацию.

## Воспроизведение

Нужны Python 3.12, зависимости backend, torch 2.13.0 и transformers 5.14.1. Ревизия Qwen3-1.7B — `70d244cc86ccca08cf5af4e1e306ecf908b1ad5e`. Выполнить из корня checkout с указанным кодом в окружении с этими пакетами. Для нового результата выбрать свободный каталог.

```sh
archive=data/raw/mipt_mail_search_participants.zip
out=reports/quality/runs/mail-facts-reproduction
mkdir -p "$out"
hf download Qwen/Qwen3-1.7B --revision 70d244cc86ccca08cf5af4e1e306ecf908b1ad5e --local-dir artifacts/models/qwen3-17
python experiments/mail-facts/check.py prepare "$archive" "$out/input.jsonl"
PYTHONPATH=backend/src python experiments/mail-facts/extract.py artifacts/models/qwen3-17 "$out/input.jsonl" "$out/output.jsonl" --batch 12
python experiments/mail-facts/check.py score "$archive" "$out/output.jsonl"
```

Для собственных текстов достаточно файла JSONL с полями id, kind (letter или query), text и необязательным doc_dt или query_date в ISO. Данные корпуса и ответы на отдельные письма остаются в локальной папке прогона.
