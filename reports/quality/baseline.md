# Первый бейзлайн: BM25 с ящиком и датой

Архивный исходный результат до переноса модулей в `backend/src/mail_search/` получен 21 ноября 2026 года на публичном наборе: **16 376 писем, 99 запросов, 565 связей релевантности**. Обработаны все запросы, ошибок — **0**.

Этот результат фиксирует начальную точку до улучшений. Значения K и макроусреднение выбраны для локального eval; официальные K и веса итогового балла ещё неизвестны.

## Настройки и воспроизведение

- Ветка разработки: `codex/eval-baseline`.
- Движок исходного прогона: `mailsearch.baseline:create_engine`; после переноса — `mail_search.search.bm25:create_engine`.
- Конфигурация: `k1 = 1.2`, `b = 0.75`, `date_filter = true`.
- Фильтры: выбранный ящик, доступность письма на `query_date`, распознанный календарный день из запроса.
- Токенизация без морфологии, синонимов, embeddings и reranking.
- Fingerprint набора: `0daa664136d798c1ed2fe50802a7d236f93b4891d56f2353bc5b807b56601665`.
- SHA-256 исходников eval и движка: `f315d23cdd6e7a7ca9e51cc5aefe5d7edd7328e86fb62759cba4295c1c1035fe`.
- На момент запуска базовый Git commit: `8d705230fb064f12dff11e825abf5a5ee788a1df`, исходники eval ещё не были закоммичены (`git_dirty = true`). Поэтому версия выполнявшегося кода определяется также приведённым SHA-256, а не только commit.

```bash
uv run --project backend --locked mailsearch validate
uv run --project backend --locked mailsearch run --output reports/quality/runs/bm25-reproduction
```

Данные ожидаются в `data/raw/mipt_mail_search_participants.zip`; можно передать `--dataset` явно. Подробности: [EVAL.md](../../EVAL.md).

Полные артефакты исходного прогона сохранены локально в `runs/bm25-baseline/`: `run.json`, `metrics.json`, `per_query.jsonl`, `predictions.jsonl`, `report.md`. Исходные данные и папка прогонов исключены из Git. Новые прогоны сохраняются в отдельные папки.

Измерен один последовательный проход без отдельного прогрева, методом nearest rank. Время включает вызов `search` и получение его результатов; загрузка данных, построение индекса, валидация выдачи и метрики в него не входят.

**Это не серверный p99 и не подтверждение выполнения официального ограничения под нагрузкой.** Backend и нагрузочный сценарий остаются отдельным этапом. Время зависит от оборудования и условий запуска.

## Наблюдения для следующих экспериментов

- У 29 запросов выдача пустая.
- У 36 запросов Recall@10 равен 0; у 35 он равен 1.
- У 28 запросов nDCG@10 равен 1.
- Фильтр распознанного дня сохраняет все 565 размеченных релевантных пар: ошибок исключения по дате на публичном наборе не обнаружено.
- В top-100 пропущены 389 релевантных пар. У всех этих пар отсутствует пересечение токенов письма с запросом после удаления распознанной даты. Текущий BM25 возвращает только документы с общими токенами.

Эти наблюдения дают основу для сравнения следующих вариантов обработки русского текста и семантического поиска. Увеличение K само по себе не устраняет отсутствие общих токенов. Улучшения в этот исходный результат не включены; приватный набор не проверялся.
