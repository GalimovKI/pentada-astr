# Полный прогон E5 с извлечением дат и отправителя

Эксперимент `20261121T141018Z-ea134e04`, ветка `timofey-research`, код итогового прогона `8f1424bc1e7e62a7ca5c333c09998415d9f4e14b`. Инференс выполнен на A100 Brain Lab. Использованы все 16 376 писем официального архива, все 99 публичных запросов, прежние 76 адресных запросов и отдельный искусственный ящик из 72 писем для 16 контрастных запросов. Сохранённые выдачи чистого E5 предыдущего и нового прогонов совпали по всем трём наборам.

Qwen3-1.7B применяется к каждому письму и запросу с промптами и проверками доказательных фрагментов из [пилота извлечения](mail-facts.md). Границы ящика и доступность на дату запроса сохраняются. E5 кодирует почтовый текст и запрос так же, как в [контроле с правилами](soft-metadata.md). При ранжировании дата получения сопоставляется с doc_dt. Дата события и дедлайн сопоставляются с ближайшей нормализованной датой той же роли в письме. Бонус за день равен 0,16 × exp(−расхождение в днях / 1,5), за совпадение автора — 0,12. Email сравниваются после приведения регистра, для имён требуется наличие всех стеммированных токенов из запроса. Пустое поле не даёт бонуса. Адресат и упомянутые люди не являются выходами этого экстрактора. Разметка релевантности используется при оценке и построении диагностической выборки, в модель для извлечения она не передавалась.

## Покрытие извлечения

| Вход | Обработано | Ошибки формата до / после повтора | Автор заполнен | Есть нормализованная дата в тексте |
| --- | ---: | ---: | ---: | ---: |
| Письма корпуса | 16376 | 366 / 10 | 8699 | 15672 |
| Публичные запросы | 99 | 0 / 0 | 0 | 99 |
| Адресные запросы | 76 | 0 / 0 | 76 | 76 |
| Письма контрольного ящика | 72 | 0 / 0 | 72 | 72 |
| Контрастные запросы | 16 | 1 / 1 | 4 | 8 |

Некорректные ответы первого прохода сохранены отдельно. 367 таких записей обработаны повторно с ограничением на JSON-схему. Для оставшихся 18 записей выполнен третий проход через Transformers с batch size 1. Письма с ошибкой остались в поисковом индексе и участвовали в ранжировании. Частично отклонённые поля ответа и заполненность метаданных описывают работу экстрактора. У корпуса отсутствует исчерпывающая разметка точности авторов и дат событий.

Публичные запросы указывают дату получения. По ним можно оценить распознавание дня, но польза извлечения дат событий и авторов из писем требует дополнительных запросов. Адресная разметка построена автоматически по явным заголовкам и публичным qrels. Контрастные запросы различают роли на искусственных письмах. На публичном наборе замена правил на Qwen сохранила nDCG@10. На обоих диагностических наборах мягкие правила дали лучший результат. Качество на приватных запросах остаётся неизвестным.

## Сколько занимает поиск

На одной A100 Brain Lab последовательно выполнены все 99 публичных запросов после трёх прогревочных запросов. Письма уже проиндексированы, результаты поиска и эмбеддинги запросов не кешировались. В vLLM включён кеш общих префиксов. Таймер охватывает формирование промпта, генерацию и валидацию JSON, кодирование запроса и выдачу. Сеть, очередь API, загрузка весов и индекса находятся за границами замера. Измерение выполнено с метаданными писем после второго прохода.

| Этап, мс | Среднее | p50 | p95 | p99 |
| --- | ---: | ---: | ---: | ---: |
| Qwen3-1.7B, извлечение даты и автора | 338,1 | 348,0 | 416,5 | 526,3 |
| Кодирование запроса E5 | 10,0 | 8,6 | 15,5 | 17,6 |
| Ранжирование | 2,5 | 2,1 | 4,4 | 12,4 |
| Полный запрос | 350,5 | 359,1 | 430,0 | 545,9 |

При пакетной обработке первый проход Qwen занял 652 с на 16 639 входов, в среднем 39,2 мс на вход при параллельной обработке. В этот объём входят 16 376 писем корпуса, 72 искусственных письма и 191 запрос. Первый повтор 367 входов занял ещё 48 с. Последний повтор 18 входов занял 153,4 с с загрузкой модели в отдельном процессе. Сумма трёх интервалов составила 14 мин 13 с. После всех повторов некорректный ответ остался у 10 писем корпуса и одного искусственного запроса. Все 99 публичных запросов прошли валидацию JSON при последовательном замере. Для каждого из них топ-100 полностью совпал с итоговой пакетной выдачей.

## Воспроизведение

Нужны официальный архив, подготовленный матричный индекс E5 и закреплённые веса Qwen3-1.7B (70d244cc86ccca08cf5af4e1e306ecf908b1ad5e). Версия E5 — 614241f622f53c4eeff9890bdc4f31cfecc418b3. Построение индекса описано в [первом сравнении](soft-metadata.md). Для общего eval использована среда Python 3.12 + torch 2.13.0 + transformers 5.14.1; для пакетной генерации — vLLM 0.11.0, torch 2.8.0, transformers 4.57.6, режим greedy, BF16. Команды ниже выполняются на коде итогового прогона в свежем каталоге результатов. Переменные ML_PY и VLLM_PY указывают на интерпретаторы с соответствующими зависимостями. E5_REF указывает на корень checkout прототипа 80dbbe3.

```sh
export PYTHONPATH="backend/src:experiments/soft-metadata:$E5_REF/experiments/mailsearch-e5"
export OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 TOKENIZERS_PARALLELISM=false
archive=data/raw/mipt_mail_search_participants.zip
index=artifacts/indexes/soft-e5.npz
qwen=artifacts/models/qwen3-17
out=reports/quality/runs/full-reproduction
mkdir -p "$out"
"$ML_PY" experiments/mail-facts/full_inputs.py "$archive" "$out/inputs.jsonl"
"$VLLM_PY" experiments/mail-facts/bulk.py "$qwen" "$out/inputs.jsonl" "$out/chunks"
"$VLLM_PY" experiments/mail-facts/bulk.py "$qwen" "$out/inputs.jsonl" "$out/repairs" --repair-from "$out/chunks"
mkdir -p "$out/fallback"
"$ML_PY" - "$out" <<'PYTHON'
import json
import sys
from pathlib import Path
out = Path(sys.argv[1])
failed = {r["id"] for p in (out / "repairs").glob("*.jsonl")
          for r in map(json.loads, p.read_text().splitlines()) if "error" in r}
with (out / "last-inputs.jsonl").open("w") as dst:
    for line in (out / "inputs.jsonl").read_text().splitlines():
        if json.loads(line)["id"] in failed:
            print(line, file=dst)
PYTHON
"$ML_PY" experiments/mail-facts/extract.py "$qwen" "$out/last-inputs.jsonl" "$out/fallback/last.jsonl" --batch 1
"$VLLM_PY" experiments/mail-facts/latency.py "$archive" "$index" "$out/chunks" "$out/repairs" "$qwen" "$out/latency.json"
"$ML_PY" experiments/mail-facts/retrieve.py "$archive" "$index" "$out/chunks" "$out/scores" --repairs "$out/repairs" --repairs "$out/fallback"
uv run --project backend --locked mailsearch score --predictions "$out/scores/public/full/predictions.jsonl" --output "$out/verified"
```

Fingerprint публичного бенчмарка общего eval — 0daa664136d798c1ed2fe50802a7d236f93b4891d56f2353bc5b807b56601665. Код проверяет SHA-256 исходного архива для векторного индекса, ID документов и полноту извлечённых записей.
